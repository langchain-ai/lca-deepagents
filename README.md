# Deep Agents

Course materials for the [Deep Agents](https://academy.langchain.com/courses/foundation-introduction-to-deepagents) course on LangChain Academy.

## Contents

- **[python/](python/)**: Python implementation. See [python/README.md](python/README.md) for setup instructions.
- **[typescript/](typescript/)**: TypeScript implementation. See [typescript/README.md](typescript/README.md) for setup instructions.
- **[thinkific/](thinkific/)**: source for the lesson pages, written in Markdown with embedded HTML. These files are built into the lessons you read on [LangChain Academy](https://academy.langchain.com/courses/foundation-introduction-to-deepagents), so they won't render fully on GitHub. Follow the course there and use this repo for the code.
- **[agent-chat-ui/](agent-chat-ui/)**: fork of [langchain-ai/agent-chat-ui](https://github.com/langchain-ai/agent-chat-ui) with additions for lesson 5.5, "The Sales Assistant (Advanced)". Other lessons use the hosted UI instead.
